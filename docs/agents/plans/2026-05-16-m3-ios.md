# M3 — Kino-iOS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> This plan covers all of F-278 (M3). It is decomposed into ten sub-issues (M3.0–M3.9), each landing as its own PR on its own branch. M3.0 lives in the `kino` server repo; M3.1–M3.9 live in `kino-apple`. The companion design spec is at `docs/agents/specs/2026-05-16-m3-ios-design.md`.

**Goal:** Ship a TestFlight-able iOS app that meets F-278's per-platform exit bar against KinoKit (frozen at the close of this milestone).

**Architecture:** SwiftUI throughout, iOS 17 deployment target with iOS 26 Liquid Glass styling. `@Observable` view-models per screen, single `AppState` for auth + global error. 4-tab Liquid Glass capsule nav (Home / Movies / Shows / Search) plus an Account sheet behind a top-right avatar (Requests + Settings + Sign Out). `AVPlayerViewController` for playback. `NavigationSplitView` adaptation for iPad.

**Tech Stack:** Swift 6.x, SwiftUI, `@Observable` macro, `AVFoundation` (`AVPlayerViewController`), `Network.framework` (via KinoKit's `ServerDiscovery`), KinoKit (frozen at M3 close).

## Universal conventions

- **Commit messages** match `AGENTS.md`: one line, semantic prefix, no body. Allowed prefixes (`feat`, `fix`, `chore`, `refactor`, `test`, `docs`, `perf`, `build`). Allowed scopes for M3: `ios`, `repo`, `agents`, `docs`. **Never** `Co-Authored-By`, no agent attribution, no multi-line bodies.
- **Branch names** follow Linear's `gitBranchName` field for each sub-issue.
- **Pre-commit hook** runs `just fmt-check` + `just lint` on staged `.swift` files. Don't bypass with `--no-verify`. Run `just fmt` to autofix.
- **Verify before claiming done:** every task ends by running `just build && just test && just fmt-check && just lint`. The Xcode app builds are the primary verification gate — there are very few unit tests in M3 (per spec §5).
- **No new SwiftPM dependencies.** iOS uses what KinoKit provides plus the Apple frameworks (`SwiftUI`, `AVFoundation`, `Combine` is **not** used).
- **`os.Logger`** subsystem `"kino.ios"`, category per screen (`"home"`, `"movies"`, `"search"`, `"pairing"`, `"player"`). No `print` outside the `@main` entry point.
- **Public symbols** inside the app target are conventionally `internal` (default); SwiftUI views and view-models are `internal`. No `public` access modifiers in the app code.
- **Strict concurrency** stays on. Every view-model is `@MainActor`; closures crossing actor boundaries are `@Sendable`.
- **No SwiftUI snapshot tests** per Phase 4 spec §9.

- [ ] **Step 3: Implement `AppState.swift`.**

  ```swift
  import Foundation
  import Observation
  import KinoKit
  import os

  enum AppPhase: Sendable {
    case loading
    case unauthenticated
    case authenticated(KinoClient)
    case error(KinoError)
  }

  @Observable
  @MainActor
  final class AppState {
    private let store: any SessionStore
    private let logger = Logger(subsystem: "kino.ios", category: "appstate")

    var phase: AppPhase = .loading
    var errorBanner: KinoError?

    init(store: any SessionStore = KeychainSessionStore()) {
      self.store = store
      Task { await self.loadSession() }
    }

    func loadSession() async {
      do {
        let sessions = try await store.loadAll()
        guard let session = sessions.last else {
          phase = .unauthenticated
          return
        }
        phase = .authenticated(KinoClient(session: session))
      } catch let error as KinoError {
        phase = .error(error)
      } catch {
        phase = .error(.decoding(error))
      }
    }

    func signedIn(_ session: AuthorizedSession) async {
      do { try await store.save(session) } catch {
        logger.error("Failed to persist session: \(String(describing: error))")
      }
      phase = .authenticated(KinoClient(session: session))
    }

    func signOut() async {
      guard case .authenticated(let client) = phase else { return }
      try? await store.remove(serverInstanceID: client.session.serverInstanceID)
      phase = .unauthenticated
    }
  }
  ```

- [ ] **Step 5: Implement `Components/KinoAsyncImage.swift`.**

  ```swift
  import SwiftUI
  import KinoKit

  struct KinoAsyncImage: View {
    let url: URL?
    let isInternal: Bool                      // true for kino-server-hosted; false for TMDB
    var cornerRadius: CGFloat = 8

    @Environment(\.kinoClient) private var client

    var body: some View {
      AsyncImage(url: url, transaction: .init(animation: .easeOut(duration: 0.18))) { phase in
        switch phase {
        case .success(let image):
          image.resizable().aspectRatio(contentMode: .fill)
        case .failure, .empty:
          Rectangle().fill(Color(.tertiarySystemFill))
        @unknown default:
          Rectangle().fill(Color(.tertiarySystemFill))
        }
      }
      .clipShape(RoundedRectangle(cornerRadius: cornerRadius))
      .overlay(
        // Subtle inner highlight + drop shadow for the Apple TV+ feel.
        RoundedRectangle(cornerRadius: cornerRadius)
          .stroke(LinearGradient(
            colors: [.white.opacity(0.12), .clear, .black.opacity(0.18)],
            startPoint: .topLeading, endPoint: .bottomTrailing
          ), lineWidth: 0.5)
      )
    }
  }
  ```

  Note: `AsyncImage` uses the shared `URLSession.shared` by default, which doesn't carry our auth header. For now, accept that internal images load unauthenticated (the server's image endpoints currently allow this per the existing M2 spec). If kino-server later requires auth on `/library/items/{id}/images/{kind}`, swap in a custom `URLSession` configured via `KinoClient.transport.urlSession`. **Track this as a known limitation; don't add complexity now.**

  ```swift
  import Foundation
  import Observation
  import KinoKit
  import os

  @Observable
  @MainActor
  final class PairingViewModel {
    enum Phase: Sendable {
      case discovering([DiscoveredServer])
      case manualEntry
      case requestingCode(ResolvedServer)
      case awaitingApproval(PairingChallenge, ResolvedServer)
      case failed(PairingError)
    }

    private let logger = Logger(subsystem: "kino.ios", category: "pairing")
    private var discoveryTask: Task<Void, Never>?
    private var pollTask: Task<Void, Never>?

    var phase: Phase = .discovering([])

    func startDiscovery() {
      discoveryTask?.cancel()
      discoveryTask = Task {
        let discovery = ServerDiscovery()
        for await server in await discovery.browse() {
          guard case .discovering(var current) = self.phase else { return }
          if !current.contains(where: { $0.instanceID == server.instanceID }) {
            current.append(server)
            self.phase = .discovering(current)
          }
        }
      }
    }

    func stopDiscovery() {
      discoveryTask?.cancel(); discoveryTask = nil
    }

    func select(_ server: DiscoveredServer) async {
      let discovery = ServerDiscovery()
      do {
        let resolved = try await discovery.resolve(server)
        await requestCode(for: resolved)
      } catch {
        logger.error("resolve failed: \(String(describing: error))")
        phase = .failed(.malformedResponse)
      }
    }

    func enterManualURL(_ raw: String) async {
      guard let url = URL(string: raw), let host = url.host else {
        phase = .failed(.malformedResponse); return
      }
      let resolved = ResolvedServer(
        instanceID: UUID(), host: host, port: url.port ?? 80,
        apiVersion: "v1", serverVersion: "unknown"
      )
      await requestCode(for: resolved)
    }

    private func requestCode(for server: ResolvedServer) async {
      phase = .requestingCode(server)
      let client = PairingClient(server: server)
      do {
        let challenge = try await client.requestCode(
          deviceName: deviceName(),
          platform: .iOS
        )
        phase = .awaitingApproval(challenge, server)
        startPolling(challenge: challenge, server: server)
      } catch let error as PairingError {
        phase = .failed(error)
      } catch {
        phase = .failed(.malformedResponse)
      }
    }

    private func startPolling(challenge: PairingChallenge, server: ResolvedServer) {
      pollTask?.cancel()
      pollTask = Task { [appState] in
        do {
          let client = PairingClient(server: server)
          let session = try await client.awaitApproval(challenge)
          await appState?.signedIn(session)
        } catch let error as PairingError {
          self.phase = .failed(error)
        } catch {
          self.phase = .failed(.malformedResponse)
        }
      }
    }

    private weak var appState: AppState?
    func bind(_ state: AppState) { self.appState = state }

    func reset() {
      pollTask?.cancel(); pollTask = nil
      phase = .discovering([])
      startDiscovery()
    }

    private func deviceName() -> String {
      UIDevice.current.name
    }
  }
  ```

  ```swift
      isLoading = true; defer { isLoading = false }
      do {
        let batch = try await client.library.list(
          kind: kind.rawValue,
          limit: pageSize,
          offset: offset,
          q: nil
        )
        items.append(contentsOf: batch)
        offset += batch.count
        if batch.count < pageSize { hasMore = false }
      } catch let e as KinoError {
        error = e
      } catch {
        error = .decoding(error)
      }
    }
  }
  ```

- [ ] **Step 3: Implement `PlayerContainer.swift`.**

  Owns the `PlaybackCoordinator` lifecycle. On `task`: prepare → make AVPlayerItem → instantiate AVPlayer → start reporting. On dismiss: stop reporting.

  ```swift
  import SwiftUI
  import AVFoundation
  import KinoKit

  struct PlayerContainer: View {
    let item: MediaItem
    @Environment(\.kinoClient) private var client
    @Environment(\.dismiss) private var dismiss
    @State private var player: AVPlayer?
    @State private var coordinator: PlaybackCoordinator?
    @State private var error: KinoError?

    var body: some View {
      Group {
        if let player {
          AVPlayerViewControllerRepresentable(player: player)
        } else if error != nil {
          // Error UI with retry
        } else {
          ProgressView()
        }
      }
      .ignoresSafeArea()
      .task { await start() }
      .onDisappear { Task { await coordinator?.stopReporting() } }
    }

    private func start() async {
      guard let client else { return }
      let caps = ClientCapabilities.iOS17Default() // helper; or inline a sensible default
      let coord = PlaybackCoordinator(client: client, item: item, capabilities: caps)
      coordinator = coord
      do {
        let plan = try await coord.prepare()
        let playerItem = await coord.makePlayerItem(plan)
        let p = AVPlayer(playerItem: playerItem)
        player = p
        await coord.startReporting(player: p)
        p.play()
      } catch let e as KinoError {
        error = e
      } catch {
        self.error = .decoding(error)
      }
    }
  }
  ```

  `ClientCapabilities.iOS17Default()` is a small helper that returns the static capability set for an iPhone running iOS 17+: `codecs: [.h264, .hevc, .av1]`, `hdr: [.hdr10, .dolbyVision]`, `maxHeight: 2160`, `surroundAudio: true`, `atmos: true`. Add it as a static method on `ClientCapabilities` if KinoKit doesn't have it; or inline.
